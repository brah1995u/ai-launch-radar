# Короткий план сайту — AI Launch Radar

**Мета:** допомогти швидко знайти AI-сайти, зрозуміти їхню спеціалізацію та порівняти 2–3 кандидати за даними FreeSERP.

**Аудиторія:** розробники, засновники, маркетологи, SEO-фахівці та дослідники продуктів, які шукають інструменти або конкурентів.

| Сторінка | Структура та призначення |
| --- | --- |
| `/` — каталог | Короткий вступ → статистика AI-ніші → пошук → швидкі категорії й фільтри → кількість результатів та активні фільтри → картки → Load more. Панель вибраних сайтів веде до порівняння. |
| `/site/[domain]` — сайт | Повернення до результатів → назва, домен, категорії → повний опис → DR, технологія, дати, TLD і HTTP-статус → Visit website та додавання до порівняння. |
| `/compare?domain=…&domain=…` — порівняння | Повернення до каталогу → 2–3 сайти у стовпцях → короткі описи з переходом до повного → категорії, DR, технологія, дати й технічні сигнали → посилання на сайти. На телефоні таблиця прокручується всередині контейнера. |
| `/about` — про дані | Призначення проєкту → джерело та спосіб відбору AI-ніші → пояснення кожного сигналу → обмеження даних → повернення до каталогу. |

**Спільні елементи:** навігація Discover / About the data, видимий фокус клавіатури, skip-link, підвал із джерелом. На мобільному фільтри розкриваються кнопкою, категорії прокручуються горизонтально, вибір для порівняння редагується окремо.

**Основний сценарій:** пошук або категорія → уточнення фільтрів → перегляд опису сайту → повернення до тієї самої добірки → додавання 2–3 сайтів → порівняння → перехід на сайт. Фільтри й домени порівняння зберігаються в URL для повторного відкриття та поширення.

**Стани:** завантаження, порожня вибірка з очищенням фільтрів, помилка з повторною спробою, відсутній точний домен, часткова помилка порівняння та відсутні поля. Дані не підміняються демонстраційними; дата виявлення не називається офіційним запуском, DR не використовується як оцінка якості продукту.

**Межі тестового:** публічний API без ключа, головні сторінки `index=sites`, AI-ніша `ai_startups=1`, без акаунтів і бази даних. Результат — робочий вихідний архів, README, цей план та докази перевірок.
