**Тема:** Тестове завдання — AI Launch Radar

Доброго дня! Надсилаю виконане тестове завдання — AI Launch Radar, каталог AI-сайтів із пошуком, фільтрами, деталями та порівнянням 2–3 сайтів.

Проєкт використовує реальний публічний FreeSERP API без ключа та реєстрації: головні сторінки `index=sites`, AI-ніша `ai_startups=1`. Роботу виконано через Codex.

В архіві є вихідний код, короткий README з командами запуску, план сайту та результати перевірок. Для запуску потрібні Node.js 24 та команди `npm ci`, `npm run build`, `npm start`.

Пройшли 63 модульні/компонентні тести, 14 браузерних сценаріїв, lint, перевірка типів і production build. Обмеження джерела даних та можливі наступні покращення описані в README.

Дякую! Буду радий обговорити рішення та відповісти на запитання.
